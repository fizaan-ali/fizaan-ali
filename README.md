## 🚀 Featured Work

### 🤖 [Bob — Terminal Assistant](https://github.com/fizaan-ali/Bob_Terminal-Assistant)
**Python · Groq API · LLaMA · Regular Expressions · Text-to-Speech · pytest**

A terminal-based assistant that interprets natural-language commands to open applications, search the web, ask an AI model questions, and speak generated jokes. Its code is split into focused modules, API secrets are configured through environment variables, and tests cover core parsing and URL-building logic.

**Why it matters:** It brings together Python, API integration, modular code, environment-variable handling, and testing in one usable application.

### 🚲 [Cyclistic Bike-Share Analysis](https://github.com/fizaan-ali/cyclistic_bike_share_case_study)
**Python · Pandas · Jupyter Notebook · Data Analytics**

A case study comparing ride patterns between annual members and casual riders. The analysis involved cleaning and combining data, investigating unusual ride durations and timestamp discrepancies, and communicating findings in a presentation.

**Key takeaway:** The project required data judgment as well as coding—documenting anomalies instead of changing data without evidence.

### 💻 [Software Engineering Project](https://github.com/fizaan-ali/SoftwareEngineeringProject)
**C++ · SQLite · OOP · UML · Project Documentation**

A semester project demonstrating account-management functionality with database-backed persistence. The repository includes source code, UML diagrams, a project report, and compilation instructions.

**Why it matters:** It connects implementation with database design, software structure, and technical documentation.
